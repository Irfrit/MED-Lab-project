# MED Lab project

Group project for Lab in Methods of Data Exploration.

## Tasks
- Meta: fit regression models and compare forecasts for 2018–2025 with actual data.
- Body fat: model Pct.BF, explain variable selection, and model another outcome.

## Setup
Create and activate a project virtual environment, then install packages:

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -r requirements.txt

## Project folders
- `data/raw/` — supplied source data; keep originals unchanged
- `data/processed/` — cleaned or derived data
- `references/` — assignment and submission instructions
- `src/` — analysis code
- `notebooks/` — exploratory analysis
- `reports/` — report drafts
- `figures/` — generated charts
